# Dokumentacja produktu

Umieść tutaj eksport specyfikacji jako `spec-traintrack.md`:
otwórz dokument „Specyfikacja: aplikacja do śledzenia treningów i karnetów” w Claude
→ menu pod nazwą dokumentu → Export → Markdown.

W pierwszej sesji Claude Code dzieli ten plik na:

- `product-brief.md` – problem, użytkownicy, zakres MVP, kryteria sukcesu
- `roles-and-permissions.md` – role i macierz RBAC
- `user-stories.md` – historie użytkowników
- `business-rules.md` – reguły pakietów, sesji, odwołań, karnetów, przypomnień
- `screens.md` – ekrany i makiety

oraz w `docs/architecture/`:

- `database.md` – model danych
- `api.md` – projekt REST API
- `security.md` – uwierzytelnianie, tokeny, autoryzacja
- `overview.md` – architektura backendu i frontendu
- `notifications.md` – zadania w tle i przypomnienia
